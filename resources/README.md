# منبع تصویر Splash Screen

فایل `resources/splash.png` از قبل آماده است — لوگوی واقعی IHMS، با
پس‌زمینه‌ی حذف‌شده و روی بوم سرمه‌ای برند (#0E2A3F) در اندازه‌ی ۲۷۳۲×۲۷۳۲
پیکسل، بدون کشیدگی یا افت کیفیت. نیازی به هیچ کاری از این بابت نیست.

## کاری که باید انجام بدهید

فقط کافی‌ست این دستور را بزنید تا تصاویر لازم برای همه‌ی چگالی‌های اندروید
خودکار ساخته و در پوشه‌ی `android/app/src/main/res/` قرار بگیرند:

```
npm run cap:assets
```

(اگر پوشه‌ی android هنوز نساخته‌اید، اول `npm run cap:add` را بزنید.)

اگر از GitHub Actions برای ساخت APK استفاده می‌کنید، این مرحله از قبل در
workflow اتوماتیک انجام می‌شود — کافی‌ست همین فایل `splash.png` را در
ریپو commit/push کنید و workflow را Run کنید.

## اگر خواستید بعداً لوگو را عوض کنید

کافی‌ست همین فایل را با نسخه‌ی جدید (ترجیحاً حداقل ۱۰۰۰×۱۰۰۰ پیکسل، با
بک‌گراند تقریباً یکدست) جایگزین کنید و دوباره `npm run cap:assets` را
بزنید.
