# منبع تصویر Splash Screen

این پوشه محل استانداردی است که ابزار رسمی `@capacitor/assets` تصویر
Splash Screen را از آن می‌خواند و برای همه‌ی چگالی‌های صفحه‌ی اندروید
(mdpi تا xxxhdpi) خودکار تولید می‌کند — بدون افت کیفیت یا کشیدگی، چون
خودِ ابزار نسبت تصویر را حفظ می‌کند.

## کاری که باید انجام بدهید

1. لوگوی واقعی IHMS (فایل PNG با بک‌گراند شفاف، حداقل ۱۰۰۰×۱۰۰۰ پیکسل،
   هرچه بزرگ‌تر بهتر) را در همین پوشه با نام دقیق زیر قرار دهید:

   ```
   resources/splash.png
   ```

   بهترین حالت: خودِ فایل ۲۷۳۲×۲۷۳۲ پیکسل باشد، لوگو دقیقاً وسط آن و بقیه‌ی
   فضا شفاف (transparent) یا هم‌رنگ با پس‌زمینه‌ی سرمه‌ای برنامه
   (#0E2A3F) باشد — این‌جوری تضمین می‌شود لوگو دقیقاً وسط صفحه در همه‌ی
   اندازه‌های گوشی/تبلت بماند.

2. دستور زیر را بزنید تا تصاویر لازم برای همه‌ی چگالی‌های اندروید خودکار
   ساخته و در پوشه‌ی `android/app/src/main/res/` قرار بگیرند:

   ```
   npm run cap:assets
   ```

   (اگر پوشه‌ی android هنوز نساخته‌اید، اول `npm run cap:add` را بزنید.)

3. بعد از آن، طبق روال همیشگی:

   ```
   npm run cap:sync
   npm run cap:open
   ```

همین. رنگ پس‌زمینه، مدت‌زمان نمایش، و انیمیشن محو شدن، همگی از قبل در
`capacitor.config.json` و `src/splashScreenControl.js` تنظیم شده‌اند —
نیازی به تغییر دستی چیز دیگری نیست.
