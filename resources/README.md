## کاری که باید انجام بدهید

فقط کافی‌ست این دستور را بزنید تا تصاویر لازم برای همه‌ی چگالی‌های اندروید
خودکار ساخته و در پوشه‌ی `android/app/src/main/res/` قرار بگیرند:

```
npm run cap:assets
```

(اگر پوشه‌ی android هنوز نساخته‌اید، اول `npm run cap:add` را بزنید.)

اگر از GitHub Actions برای ساخت APK استفاده می‌کنید، این مرحله از قبل در
workflow اتوماتیک انجام می‌شود — کافی‌ست همین فایل `splash.png` را در
ریپو commit/push کنید و workflow را Run کنید.

# منابع تصویر اپ موبایل (آیکون و Splash Screen)

## آیکون اپ (`resources/icon.png`)

برای تغییر آیکون اپ موبایل/APK:

۱. یک تصویر PNG مربعی (حداقل ۱۰۲۴×۱۰۲۴ پیکسل، ترجیحاً بدون گوشه‌های
   گردشده یا شفافیت پیچیده — خودِ ابزار گردکردن/سایه را طبق استاندارد
   اندروید اضافه می‌کند) با نام دقیق `icon.png` در همین پوشه
   (`resources/icon.png`) قرار دهید (جایگزین فایل قبلی، اگر وجود دارد).

۲. تغییر را commit و push کنید.

۳. از تب **Actions** در GitHub، workflow با نام **Build Android APK**
   را به‌صورت دستی (Run workflow) اجرا کنید. مرحله‌ی
   `Generate Splash Screen assets` در همان workflow (دستور
   `npx capacitor-assets generate --android`) آیکون جدید را خودکار در
   همه‌ی چگالی‌های لازم اندروید (mdpi تا xxxhdpi) تولید و در پروژه‌ی
   نیتیو جایگزین می‌کند — نیازی به هیچ کار دستی دیگری نیست.

می‌توانید آدرس آیکون جدید را همچنین در پنل Super Admin، بخش
«پیکربندی سامانه ← تنظیمات ظاهری ← مدیریت آیکون اپ موبایل / APK» ثبت
کنید — این فقط برای نگهداری/یادآوری آدرس فایل جهت دانلود و commit
دستی است (چون خودِ فرآیند ساخت APK روی مخزن کد در GitHub انجام
می‌شود، نه این پایگاه‌داده).
